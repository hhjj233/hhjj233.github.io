# hhjj233.github.io

Source of the personal website of Jiaxi (Jay) Liu, Ph.D. candidate in Civil and Environmental Engineering at the University of Wisconsin–Madison: https://hhjj233.github.io

The site is built with [Jekyll](https://jekyllrb.com/) from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and served by GitHub Pages from the `master` branch.

- Content: `_data/cv.json` (profile, research directions, publications, news, and teaching) and `_pages/about.md`
- Layout and style: `_layouts/`, `_includes/`, `_sass/layout/_academic.scss`, and `assets/js/academic.js`

To preview locally:

```bash
bundle install
bundle exec jekyll serve
```
